# 📘 Assignment: Python Text Processing

## 🎯 Objective

Learn to use Python strings and file input/output to analyze and transform text. You will build a program that reads a text file, reports useful information about its contents, and creates a cleaned version of the text.

## 📝 Tasks

### 🛠️ Analyze Text Content

#### Description

Write a program that reads a text file and uses string methods to count and examine its contents.

#### Requirements
Completed program should:

- Read all text from a file named `input.txt`.
- Count and display the total number of characters, words, and lines.
- Convert the text to lowercase before counting word occurrences.
- Display the number of times a word chosen by the user appears in the text.

### 🛠️ Create a Cleaned Text File

#### Description

Transform the text by removing extra spaces and blank lines, then save the cleaned text to a new file.

#### Requirements
Completed program should:

- Remove leading and trailing spaces from every line.
- Omit blank lines from the cleaned output.
- Write the cleaned text to a file named `cleaned_output.txt`.
- Display a message confirming that the cleaned file was created.
