
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a command-line Hangman game using Python strings, loops, conditionals, lists, and user input. Practice tracking game state while giving players clear feedback after each guess.

## 📝 Tasks

### 🛠️	Create the Game Setup

#### Description

Prepare the list of possible words and randomly choose one as the secret word. Initialize the variables needed to track guessed letters, incorrect guesses, and the maximum number of incorrect attempts.

#### Requirements

Completed program should:

- Store at least five possible secret words in a list.
- Randomly select one word from the list when the game starts.
- Create variables to track guessed letters and incorrect guesses.
- Set a maximum number of incorrect guesses before the player loses.

### 🛠️	Build the Guessing Loop

#### Description

Create a loop that lets the player guess one letter at a time. Display the word progress and remaining attempts, then end the game with a clear win or loss message.

#### Requirements

Completed program should:

- Display correctly guessed letters and underscores for unguessed letters.
- Accept a letter guess from the player during each turn.
- Record incorrect guesses and reduce the remaining attempts.
- End with a win message when all letters are guessed.
- End with a loss message when the maximum incorrect guesses is reached.
